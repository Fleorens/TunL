# Libellés de triage

Les skills parlent de cinq rôles de triage. Dans TunL, un rôle s'écrit dans la colonne « Statut » du tableau du
jalon, dans `tasks/README.md`. Seuls deux rôles correspondent à un statut existant.

| Rôle (mattpocock/skills) | Statut TunL | Sens |
|---|---|---|
| `needs-triage` | `à écrire` | Fiche prévue, pas encore détaillée |
| `ready-for-agent` | `prête` | Fiche complète, exécutable par un agent |
| `needs-info` | — | Non utilisé dans TunL |
| `ready-for-human` | — | Non utilisé dans TunL |
| `wontfix` | — | Non utilisé dans TunL |

Quand un skill demande un rôle non utilisé, ne crée pas de nouveau statut : signale-le à Florian.

Les statuts `livrée` et `validée` suivent l'exécution d'une fiche ; ils ne relèvent pas du triage.
